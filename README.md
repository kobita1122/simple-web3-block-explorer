# Simple Web3 Block Explorer

This is a beginner-friendly blockchain project.

This project helps you:
- Enter a block number
- Read block data from blockchain
- See block hash
- See transaction count
- Learn how blocks work

This project uses:
- HTML
- JavaScript
- Public blockchain API

## Features
- Input block number
- Fetch block data
- Show block hash
- Show transaction count
- Simple and clean layout

## Requirements
- Internet connection
- Basic JavaScript knowledge

## How to Run
1. Download this repository
2. Open `index.html` in browser
3. Enter a block number
4. Click "Search Block"
5. See block info on screen

## File Structure
- index.html -> Main webpage
- app.js -> App logic
- config.js -> API settings
- api.js -> Block API calls
- block.js -> Block logic
- hash.js -> Hash display
- txcount.js -> Transaction counter
- ui.js -> Screen updates
- validate.js -> Input validation
- utils.js -> Helper functions

## Learning Goal
This project helps beginners learn:
- What a blockchain block is
- How block data is fetched
- How blockchain explorers work
